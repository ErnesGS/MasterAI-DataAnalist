# MasterAI-DataAnalist
First impresion about ideas and products for the group

## Gafas con IA enfocada a la adaptabilidad
Un rediseño del software de las gafas con inteligencia artificial enfocado en la adaptabilidad para personas con discapacidad visual.

Avisos de semáforos en rojo y cambios de nivel (Dificultad elevada y posible descarte)

## Sistema de aproximación de aforo
Un sistema que funcione en un dron para estimar el aforo de un lugar o evento.

## Sistema de optimización de tráfico
Cogiendo datos de zonas con alto indice de tráfico en distintos eventos y horas, estudiar porque se produce dicho bloqueo y como solucionarlo (Regular tiempo de semaforos, personal de policia y logistica de las calles)

## Probador virtual
Una camara que capture el movimiento de una persona y lo pase a una aplicación con prendas vectorizadas, después se proyecta una prenda sobre la pared imitando los movimientos de la persona (la idea es crear un probador de ropa sin necesidad de cambiarse). Intentar crear una previsualización de las prendas para que los sastres puedan crear modificaciones rápidas antes de empezar a coser.
